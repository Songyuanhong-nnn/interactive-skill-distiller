交互式引导引擎

interactive-skill-distiller

一句话进来，先判断你要什么。

三条路：蒸馏成可复用的 skill、引导你把事做完、出一份能开工的计划。共用档案，全程落盘。

安装

bash
git clone https://github.com/Songyuanhong-nnn/interactive-skill-distiller.git \
  ~/.workbuddy/skills/interactive-skill-distiller

或用脚本：bash install.sh · 重启会话生效

三条路

产出结束标志
A 蒸馏可复用的 SKILL.md装进 skills 目录
B 执行这一次要的交付物过了终点判据
C 规划行动序列 + 判据 + 依赖认可后可直接开工

路线

A蒸馏P0 立项 · P1 调研 · P2 访谈 · P3 骨架 · P4 写作 · P5 安装
B引导执行G0 定终点 · G1 拆步 · G2 逐步做 · G3 校验 · G4 归档
C规划L0 边界 · L1 两条候选路 · L2 拆里程碑 · L3 出计划 · L4 转执行

会话档案

.skill-distill/sessions/<case-id>/
├── state.yaml      阶段 / 已确认维度 / 版本
├── journal.md      问答流水，只增不改
├── research.md     每条须写"改变了什么"
├── decisions.md    决策 + 被否决的方案
└── iterations/     v1.0 / v1.1 …
